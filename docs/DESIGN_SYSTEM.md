# PURIENCE — DESIGN SYSTEM SPECIFICATION

## 1. Philosophy: Anti-SaaS, Pro-Editorial

Purience purposefully departs from contemporary generic SaaS cliches:
- **NO**: Purple/blue gradients, neon accents, glassmorphism, heavy drop shadows, sterile white cards.
- **YES**: Warm ivory backgrounds, charcoal typography, burnt terracotta accents, tactile human photography, generous whitespace.

## 2. Color Palette Tokens

| Token Name | Hex Code | Visual Role |
| :--- | :--- | :--- |
| **Warm Ivory** | `#F7F4EE` | Primary editorial background |
| **Deep Charcoal** | `#191918` | Primary brand dark, headings, strong text |
| **Burnt Terracotta** | `#C65D3A` | Signature accent, primary buttons, active states |
| **Desert Clay** | `#A96F52` | Secondary warm earth, subtitles, curator quotes |
| **Sand Surface** | `#E9E0D2` | Surface tint, filter pills, borders |
| **Natural Green** | `#40584A` | Verification badges, confirmation alerts |
| **Pure White** | `#FFFFFF` | Elevated cards, overlays, inputs |
| **Muted Text** | `#6D6A64` | Secondary metadata, dates, microcopy |
| **Borders** | `#DED8CF` | Fine structural lines |

## 3. Typography

- **Editorial Headlines**: `Playfair Display` (serif, high elegance, editorial hierarchy).
- **Body & Controls**: `Plus Jakarta Sans` (contemporary sans-serif, high legibility on mobile screens).

## 4. Photography Direction

- Focus on human action + emotion + place.
- Real artisans, real fire, real tools, real horses, real ocean surf.
- Strictly avoid generic monuments or AI-rendered synthetic people.
