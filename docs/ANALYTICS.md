# PURIENCE — CONSUMER FUNNEL ANALYTICS

## 1. Funnel Event Schema

Purience tracks consumer intent across every stage of discovery:

- `homepage_view`: Landing page loaded with attribution channels.
- `destination_view`: Specific destination guide opened.
- `discover_impression`: Discover feed scrolled.
- `experience_impression`: Experience card viewed in viewport.
- `experience_click`: Experience card clicked.
- `search`: Filter or search query initiated.
- `filter_applied`: Faceted criteria applied.
- `favorite`: Experience saved to personal wishlist.
- `collection_saved`: Editorial collection saved.
- `share`: Native share, WhatsApp, or link copy executed.
- `availability_check`: Traveler selects date and checks party size.
- `checkout_started`: Traveler opens reservation form.
- `booking_completed`: Successful booking processed.
- `booking_cancelled`: Reservation cancelled.
- `referral_shared`: Referral link generated and shared.
- `referral_visit`: Traveler arrives via referral campaign.

## 2. Privacy & Compliance

All analytics instrumentation honors user privacy and avoids transmitting PII (personally identifiable information) to unencrypted logs.
